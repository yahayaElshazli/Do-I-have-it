Covers are sourced from TMDB. Your TMDB token is stored only on this device with the other app settings.

How to get a TMDB token
  1. Create or sign in to your account on TMDB.
  2. Open your account settings and go to the API section.
  3. Copy the API Read Access Token and paste it above.

TMDB provides this API free for non-commercial use with the required attribution.

How to get a token
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Under "Repository access", pick "Only select repositories" and choose this repo.
  3. Under "Permissions → Repository permissions", set Contents to Read and write.
  4. Generate it, copy it, and paste it above. It's stored only on this device.

Library and wishlist are now saved as two separate files in your repo — library.json only ever holds titles you own, wishlist.json holds ones you're hunting for. If you had a wishlist saved inside the old combined file, it's moved across automatically the first time you connect.

This product uses the TMDB API but is not endorsed or certified by TMDB.

How to get a title list out of Jellyfin

Fastest way (no plugin needed):

  1. In Jellyfin, open Dashboard → API Keys and create a key.
  2. Find your user ID: Dashboard → Users, click your user — it's in the page URL.
  3. Visit this in your browser (fill in your server, key, and user ID):
    http://SERVER:8096/Users/USER_ID/Items?api_key=API_KEY&Recursive=true&IncludeItemTypes=Movie,Series&Fields=MediaSources&SortBy=SortName
  4. Select all the JSON text that appears, copy it, and paste it into the box above.

The &Fields=MediaSources part lets format be guessed from video resolution (DVD/Blu-ray/4K) — it's approximate, so double-check a few after importing. Box sets are detected automatically. Plain lines of text work too, just without format guessing.
