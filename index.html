Library loads automatically from library.json. These settings are only needed for saving changes and TMDB cover lookups.

Build: 2026-09-27 — simplified movie and series library. If this does not match, your phone may still be showing an older cached copy.

Covers are sourced from TMDB. Your TMDB token is stored only on this device with the other app settings.

How to get a TMDB token
  1. Create or sign in to your account on TMDB.
  2. Open your account settings and go to the API section.
  3. Copy the API Read Access Token and paste it above.

TMDB provides this API free for non-commercial use with the required attribution.

How to get a token
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Under "Repository access", pick "Only select repositories" and choose this repo.
  3. Under "Permissions → Repository permissions", set Contents to Read and write.
  4. Generate it, copy it, and paste it above. It's stored only on this device.

The library is loaded directly from library.json when the app opens, so no GitHub sync is needed just to view it. Keep library.json and wishlist.json alongside the app on GitHub Pages. A GitHub token is only needed when the app saves changes. Library and wishlist are saved as two separate files in your repo — library.json only ever holds titles you own, wishlist.json holds ones you're hunting for. If you had a wishlist saved inside the old combined file, it's moved across automatically the first time you connect.

This product uses the TMDB API but is not endorsed or certified by TMDB.

How to get a title list out of Jellyfin

Fastest way (no plugin needed):

  1. In Jellyfin, open Dashboard → API Keys and create a key.
  2. Find your user ID: Dashboard → Users, click your user — it's in the page URL.
  3. Visit this in your browser (fill in your server, key, and user ID):
    http://SERVER:8096/Users/USER_ID/Items?api_key=API_KEY&Recursive=true&IncludeItemTypes=Movie,Series,BoxSet&CollapseBoxSetItems=false&Fields=MediaSources,ProviderIds,ParentId&SortBy=SortName
  4. Select all the JSON text that appears, copy it, and paste it into the box above.

The &Fields=MediaSources,ProviderIds,ParentId part supplies format details and collection IDs. Movies and series stay as individual library items; BoxSet records become Collections, and movies with a TMDB collection ID are linked to the matching collection when available. Plain lines of text work too, just without format guessing.
